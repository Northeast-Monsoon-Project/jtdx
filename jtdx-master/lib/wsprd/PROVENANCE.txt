V3.7.0 imports wsprd_utils.c/.h from beta5, adapting the existing wsprd.c
hash-file loader to use the shared bounded parser. This rejects reserved
message type 63 and invalid suffixes whose values previously wrapped in
a char, and bounds message formatting and hash-line token parsing.
tests/WsprUnpack.c derives from the same commit's test_wsprd_utils.c,
with JTDX-F negative-input/corrupt-hash-slot regressions added.

Local protections retained: negative grid validation, longitude wrapping,
nonterminated/oversized type-3 hash-slot handling, WAV/C2 length and header
checks, bounded hash storage, Fano limits and simulation input validation.
The full decoder, candidate search and FEC have not been replaced wholesale
with beta5; see docs/WSPR升级与审计_V3.6.0.txt for the earlier core upgrade.
No WSPR wire format or working-frequency policy is changed.
